# Privacy Policy — Cronos Explorer Plus

**Last updated: September 7, 2026**

Cronos Explorer Plus is an independent browser extension that adds personalization, annotation, search, transaction display, and visual customization features to the Cronos Explorer websites.

Cronos Explorer Plus is designed to operate locally in the user’s browser. It does not transmit user-created or imported extension data to the developer or to an extension-operated server.

## Information processed by the extension

To provide its functionality, Cronos Explorer Plus may process information displayed on, or retrieved from, supported Cronos Explorer pages and services, including:

- Blockchain wallet addresses
- Transaction information
- Method IDs
- Page URLs and other visible Explorer page content
- Search input entered into the Explorer interface

The extension may also process information that users choose to add or import, including:

- Private wallet name tags
- Imported Cronos account tags
- Secondary identity names and associated profile links
- Custom Method ID labels
- Theme and color preferences
- Related extension settings and metadata

When the user explicitly chooses to import account tags from Cronos Explorer, the extension may temporarily access the authentication token stored by the Cronos Explorer website and retrieve the user’s Cronos address book from the official Cronos membership service. The imported data may include wallet addresses, custom names, and related address-book metadata.

## How information is used

This information is used only to provide the extension’s functionality, including wallet annotations, identity information, Method ID labels, private-tag search, transaction display and filtering tools, transaction previews, account-tag import, and visual customization of the Cronos Explorer interface.

## Local storage

User-created and imported tags, identities, Method ID labels, preferences, and related extension data are stored locally using Chrome extension storage.

Cronos Explorer Plus does not operate a backend service or developer-controlled database for storing this information.

## Cronos Account Tag Import

Cronos Explorer Plus includes an optional feature that allows users to import address-book tags from their Cronos Explorer account.

When the user explicitly starts an import, the extension temporarily reads the existing Cronos Explorer authentication token from the Cronos Explorer website and uses it only to authenticate a request to the official Cronos membership service.

The authentication token is not stored by Cronos Explorer Plus, is not included in the imported data, and is not transmitted to the developer or to an extension-operated server.

Imported wallet addresses, custom names, and related address-book information are stored locally in Chrome extension storage and are treated as private extension data.

## Data transmission and sharing

Cronos Explorer Plus does not transmit user-created or imported extension data to the developer or to an extension-operated server.

To provide certain features, the extension may request publicly available blockchain and transaction information from Cronos Explorer. These requests are made directly between the user’s browser and Cronos Explorer and do not transmit the user’s private tags, secondary identities, custom Method ID labels, imported account tags, or extension preferences to the developer.

When the Account Tag Import feature is used, the user’s browser communicates directly with the official Cronos membership service to retrieve the user’s address book. The extension does not send the authentication token or imported address-book information to the developer or to any extension-operated service.

The extension does not use analytics, telemetry, advertising, tracking, or profiling services.

The developer does not sell user data or share user data for advertising purposes.

## External links

The extension may provide links to external websites, including Cronos Explorer and X.com. Opening these links is a user-initiated action and is subject to the privacy practices of the destination website.

## Data retention and deletion

Extension data stored in Chrome remains available until it is removed by the user, cleared from the extension, removed by clearing the extension’s local data, or removed by uninstalling the extension.

Where supported, users may also import and export their locally stored extension data.

## Chrome Web Store Limited Use

Cronos Explorer Plus uses information only as necessary to provide its disclosed functionality and in accordance with the Chrome Web Store User Data Policy and Limited Use requirements.

Cronos Explorer Plus does not:

- Sell or transfer user data to third parties outside approved use cases
- Use or transfer user data for purposes unrelated to the extension’s single purpose
- Use or transfer user data to determine creditworthiness or for lending purposes

## Independent project

Cronos Explorer Plus is an independent project and is not affiliated with, sponsored by, or endorsed by Cronos or the operators of Cronos Explorer.
